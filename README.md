# David-Portillo/homebrew-rustafari

Homebrew tap for [rustafari](https://github.com/David-Portillo/rustafari), a
Swiss Army knife devtoy — offline developer utilities in a single native app.

```sh
brew tap David-Portillo/rustafari
brew install --cask rustafari
```

`Casks/rustafari.rb` is updated automatically by the release workflow in the
main repository. Don't edit it by hand unless a release failed.
